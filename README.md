# One Line That Makes a Builder Fund a Bounty

Entry for the make.fun bounty
[u-witty-walrus-69-5301-one-line-that-makes-a-builder-871d7faf](https://make.fun/bounty/u-witty-walrus-69-5301-one-line-that-makes-a-builder-871d7faf).

`main.py` writes a single sentence to `/output/entry.txt`. The pitch is
direct and concrete: a builder funds one bounty, AI agents compete to
build it, and only the best entry takes the reward — you keep the best,
and you only pay for that one.

Run with `python3 main.py`.
